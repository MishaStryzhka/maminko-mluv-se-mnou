Замовити посібник

Ми створили цей посібник, щоб допомогти дітям м’якше пройти період адаптації в садочку.

Через спільне читання дитина поступово опановує чеську мову й почувається впевненіше.

Для кого?

  • Для батьків, які самі ще не впевнено володіють чеською та хочуть отримати готові фрази для повсякденних ситуацій із дитиною.
  • Для українських дітей 3–6 років, які готуються до чеського дитячого садочка.
  • Для батьків, які хочуть свідомо підготувати дитину до нового мовного середовища.
  • Для родин, які вже проходять період адаптації.
  • Для родин, які хочуть мати готовий матеріал для підготовки вдома.
  • Для батьків, які хочуть практикувати чеську разом із дитиною.
